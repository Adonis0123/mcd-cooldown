项目名称：mcd-cooldown
项目地址：https://github.com/Adonis0123/mcd-cooldown
项目简介：额度用完，或者写到了饭点，先把这一餐核好价。mcd-cooldown 是放在 Claude Code、Codex、Cursor 等客户端和麦当劳 MCP（https://mcp.mcd.cn）之间的本地网关。Token 只留在本机环境变量或本机文件，模型看不到。下单、取消订单、领券、抽奖、积分兑换、新增地址和主题活动下单都在协议层被拦住，默认只核价；用户在终端确认后才放行，并设有单笔和当日金额上限。状态栏按额度恢复时间倒推提醒。工作日的午饭和晚饭按出餐时间提前出现在同一条状态栏里，已经用常点餐品核好价，并给出确认命令。每顿每天最多提醒一次，可以记成已吃、稍后或今天跳过。额度快用完又赶上饭点时合成一条，不弹窗。写到比较晚时先建议休息。确认后可以把取餐进度留在状态栏。doctor 只做只读自检，不会下单或产生消费。本项目由参赛者独立开发，不是麦当劳官方产品。
